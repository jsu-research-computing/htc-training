# Module 2 — Linux and Command Line Basics

## Goals
- Navigate directories: `pwd`, `ls`, `cd`
- File operations: `mkdir`, `cp`, `mv`, `rm`
- Editing: `nano` (beginner) and `vim` (advanced)
- Permissions: `chmod`
- Pipes + redirects: `|`, `>`, `>>`
